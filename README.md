# EcoIA — ExpoSaber

Versão inicial gratuita, feita com HTML, CSS e JavaScript, sem frameworks.

## O que funciona
- Acesso à câmera pelo navegador (quando suportado e publicado em HTTPS).
- Alternativa para abrir a câmera do aparelho ou escolher uma imagem da galeria.
- Prévia da imagem.
- Conteúdo educativo sobre descarte.
- Estrutura inicial de PWA.

## O que ainda não está conectado
A análise automática por IA ainda não está configurada. O botão informa isso claramente e não inventa classificações. Para ligar uma IA real, será necessário um endpoint de servidor e um provedor que ofereça uma cota gratuita adequada. Não coloque chaves de API neste repositório.

## Publicar gratuitamente com GitHub Pages
1. Crie um repositório público chamado `ecoia-exposaber`.
2. Envie os arquivos desta pasta para a raiz do repositório.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione `main` e `/ (root)` e salve.
6. Aguarde a publicação e abra a URL exibida pelo GitHub Pages.
7. Confirme que o endereço usa HTTPS antes de testar a câmera.

GitHub Pages hospeda arquivos estáticos; não executa um backend nem guarda chaves secretas.
